# ItemVista

ItemVista is a **web-only product catalogue and sales enquiry application** built for the Officeworks engineering assessment.

**React** is used on the frontend to share components across the catalogue and keep interactive browser features consistent. **Node.js** is used on the backend to handle Fake Store API requests and SMTP enquiries asynchronously while keeping the mail configuration on the server. Both services use TypeScript.

The submission code and setup instructions are on [feature/itemvista](https://github.com/Kosuri-Pavan-Akhil/Web_Product_Catalogue-ItemVista/tree/feature/itemvista). The [full README](https://github.com/Kosuri-Pavan-Akhil/Web_Product_Catalogue-ItemVista/blob/feature/itemvista/README.md) covers Docker Compose and npm with Mailpit.

To clone the submission branch directly:

```sh
git clone --branch feature/itemvista https://github.com/Kosuri-Pavan-Akhil/Web_Product_Catalogue-ItemVista.git
```
